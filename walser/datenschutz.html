4. Karte (OpenStreetMap)

Die Anfahrtskarte wird erst geladen, wenn Sie auf «Karte laden» klicken. Dann ruft Ihr Browser Kartenkacheln von Servern der OpenStreetMap Foundation (St John’s Innovation Centre, Cowley Road, Cambridge, CB4 0WS, Vereinigtes Königreich) ab; dabei wird Ihre IP-Adresse übertragen. Ohne Klick wird keine Verbindung hergestellt. Die Kartensoftware (Leaflet) liegt auf unserem eigenen Server.

Alle Schriften liegen auf unserem eigenen Server; es werden keine Schriften von Drittanbietern nachgeladen. Diese Website setzt keine Cookies und verwendet weder Analyse- noch Werbedienste. Ihre Sprachauswahl (Deutsch, Französisch oder Englisch) wird im lokalen Speicher Ihres Browsers abgelegt; sie wird nicht an uns übertragen.
