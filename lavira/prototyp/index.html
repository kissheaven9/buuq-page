Три сценария

Новый оптовик из поиска

  1. Главная: понимает за 5 секунд «фабрика · опт · Москва · 42–64»
  2. Смотрит палитру и каталог сезона
  3. «Как купить оптом» → запрашивает прайс (форма, согласие)
  4. Получает прайс на e-mail, менеджер звонит

Постоянный клиент (магазин)

  1. Сразу в каталог, фильтр «Новинки» + свой размерный ряд
  2. Открывает модель → количество по размерам в нескольких цветах
  3. Заявка → отправка; менеджер подтверждает наличие и счёт
  4. Этап 2: личный кабинет — история, повтор заказа, цены по входу

Менеджер фабрики

  1. Получает заявку письмом (и в Telegram-бот при желании)
  2. Видит заказной лист: модель × цвет × размер × количество
  3. Проверяет наличие, выставляет счёт, меняет статус
  4. Обновляет каталог: новая модель = фото + цвета + размеры + состав
